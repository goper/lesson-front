Python с нуля: первые программы в браузере

Начните с одной строчки. Затем научите компьютер запоминать числа, читать ввод и выбирать ответ. Через восемь уроков вы самостоятельно напишете дневник чтения: он подсчитает страницы за три дня и скажет, достигнута ли цель.

Начать с урока 1 Программа курса

Тем, кто впервые пишет код. Все уроки открыты без входа и без VPN. Вход через Google или Telegram нужен только для вопросов преподавателю-нейросети.

Как устроен урок

  1. 1Разберитесь на примереПредскажите результат и проследите, как Python исполняет строки.
  2. 2Напишите свой вариантВведите код в редакторе и посмотрите, что программа выводит на ваших данных.
  3. 3Исправьте и проверьтеСравните результат с ожидаемым и проверьте решение на других значениях.
В каждом уроке есть преподаватель-нейросеть: он читает урок вместе с вами и отвечает на вопросы по нему.

Что понадобится

  • Браузер и клавиатура, подойдёт и экранная. Устанавливать Python и заводить аккаунт не требуется.
  • Умение складывать небольшие целые числа. Английские слова, которые встретятся в коде, поясняем по ходу.

После курса

Вы умеете написать небольшую программу с вводом и выводом, условием, циклом и функцией. В программе курса урок отмечается пройденным, когда ваш код проходит все его проверки.
