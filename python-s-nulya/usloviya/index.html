Выбор с if и else

Научите программу выбирать сообщение и проверьте случай точного равенства.

Читатель поставил себе цель и записал результат. Даже верная сумма ещё не отвечает на вопрос «Я справился?». Для такого ответа программе придётся выбрать одну из двух надписей. Из предыдущего урока понадобятся ввод и преобразование текста в число.

Один вопрос и два пути

Условие — это вопрос, на который можно ответить «да» или «нет». Знак >= читается «больше или равно». Выражение pages >= 20 верно для 20 и 21, но неверно для 19. Сначала полезно произнести правило вслух: достижение ровно двадцати страниц тоже считается успехом.

Слово if означает «если», else — «иначе». После условия и после else ставят двоеточие. Строку, которую следует выполнить в выбранном случае, сдвигают вправо. В курсе для одного отступа набирайте четыре пробела.

Python проверяет условие один раз, когда доходит до if. Он делает только то, что записано в выбранной ветви. Строка на прежнем уровне отступа после обеих ветвей выполнится при любом исходе.

pages = 20
if pages >= 20:
    print("Есть двадцать")
else:
    print("Читаю дальше")
print("Запись готова")

При pages = 20 какие надписи появятся и в каком порядке? Какая строка не выполнится?

Сверить прогноз

Сначала «Есть двадцать», затем «Запись готова». Условие включает равенство, поэтому команда с текстом «Читаю дальше» пропущена. Последний print стоит у левого края и не входит ни в одну ветвь.

Проверьте значения по обе стороны границы

Один удачный запуск не покажет, верно ли записано равенство. При цели 20 попробуйте 19, 20 и 21. Для 21 и знак >, и знак >= дадут одинаковый ответ. На значении 20 становится видно, какое правило вы реализовали.

В этом редакторе четыре пробела можно ввести обычной клавишей пробела. Чтобы закончить ветвь, начните следующую команду у левого края. Проверяя пример вручную, пальцем прикрывайте ветвь, которую Python должен пропустить.

Попробуйте на примере. Измените условие примера так, чтобы поздравление показывалось только за результат строго выше 20. Предскажите ответ при ровно 20 страницах.

Разобрать этот шаг

Для смысла «строго больше» нужен знак >. При ровно 20 выбранной окажется ветвь else. Для самостоятельной задачи вернитесь к правилу «достиг или превысил».

Сравните результат с целью читателя

Ввод состоит из двух чисел. Сначала результат чтения, затем личная цель. Если результат достиг цели или превысил её, выведите «Готово». В остальных случаях выведите «Ещё читаю». Нужна ровно одна строка.

Начало уже читает числа. Напишите условие и два вывода. Проверьте три случая вручную: меньше цели на одну страницу, точное совпадение и больше цели на одну страницу.

Первая строка — прочитанные страницы, вторая — цель.

Нужна подсказка

Подставьте имена вместо чисел в сравнении «результат больше или равен цели». Команды print принадлежат разным ветвям, каждая со своим отступом.

Как найти ошибку

Если выводятся обе надписи, посмотрите, не оказался ли второй print вне ветви else. При верной записи в этот момент выполняется ровно один из двух выводов.

Если ошибка сообщает про отступ, посмотрите на строку сразу после двоеточия. Без сдвига Python не видит тела ветви. Если программа запускается, но ошибается только при равенстве, сравните формулировку задания со знаком в условии.

Разберите неверное поздравление

Читатель запланировал 12 страниц, а прочитал только 8. В примере ниже программа поздравляет его раньше времени. На листке запишите три пары чисел: 8 и 12, 12 и 12, 15 и 12. Для каждой ответьте отдельно, какое сообщение должно появиться по смыслу и какое появится по этому коду. Затем измените одну строку так, чтобы смысл и результат совпали для всех пар.

pages = 8
goal = 12
if goal >= pages:
    print("Готово")
else:
    print("Ещё читаю")
Посмотреть разбор ошибки

Вопрос программы звучит как «цель больше или равна результату?». Он даст утвердительный ответ даже читателю, который ещё не дочитал. Переставьте имена по сторонам знака или поменяйте направление сравнения. Теперь прочитайте условие слева направо и прогоните все три пары. Случай равенства раньше и теперь даёт одинаковый ответ, поэтому одним таким примером перепутанное направление обнаружить невозможно.

Проверьте себя на другой задаче

В шкаф помещается коробка высотой до 30 сантиметров включительно. Какой знак нужен, если сравнение начинается с высоты коробки? Назовите три высоты для проверки.

Сверить ход решения

Подойдёт height <= 30. Попробуйте 29, 30 и 31. Ровно 30 помещается. Вы проверили тот же пограничный случай у правила, направленного в другую сторону.
