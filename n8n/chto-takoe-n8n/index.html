Что такое n8n и зачем он нужен

Знакомимся с конструктором автоматизаций и тремя главными словами: workflow, нода, триггер.

Основная идея урока

n8n — это конструктор, в котором вы соединяете готовые кубики в цепочку, и эта цепочка делает рутинную работу за вас. Программировать не нужно: вы просто говорите, когда запускаться и что делать по шагам.

Начнём с обычной рутины

Представьте небольшой интернет-магазин. Каждый день на почту приходят заявки от покупателей. Менеджер открывает письмо, копирует имя и сумму в Google-таблицу, а потом пишет в Telegram: «Новая заявка на 1 200 рублей». Три действия, по 2 минуты каждое, 30 раз в день. Это час жизни на копирование.

n8n берёт такую рутину на себя. Вы один раз описываете цепочку: «когда пришло письмо → записать в таблицу → отправить в Telegram». Дальше цепочка работает сама, круглые сутки, без выходных.

Пришло письмо → Записать строку → Сообщить менеджеру

Так эта цепочка выглядит в n8n. Три кубика, две стрелки.
Прогноз. Из цепочки убрали первый кубик «Пришло письмо». Остались «Записать строку» и «Сообщить менеджеру». Что будет делать такая цепочка?

Ничего и никогда. Первый кубик отвечал на вопрос «когда запускаться?», без него цепочка не знает, что пора начинать. Такие кубики называются триггерами, и без триггера workflow не стартует, сколько бы шагов в нём ни было. Если вы ответили «будет работать, но без данных письма», это логично, но n8n даже не попробует: запускать некому.

Три слова, без которых не обойтись

В n8n всё строится из трёх понятий. Запомните их, они будут в каждом уроке.

  • Workflow (воркфлоу, «рабочий поток») — вся цепочка целиком. Как рецепт: список шагов от начала до конца. На картинке выше workflow — это все три кубика вместе со стрелками.
  • Нода (node, «узел») — один кубик, один шаг. Каждая нода умеет делать что-то одно: отправить письмо, записать строку, проверить условие. На картинке три ноды.
  • Триггер (trigger, «спусковой крючок») — особая нода, которая стоит первой и отвечает на вопрос «когда запускать?». Пришло письмо, наступило 9 утра, кто-то заполнил форму. Без триггера workflow не запустится.
!
Формула любого workflow

Workflow = один триггер («когда») + цепочка нод («что делать»). Данные идут по стрелкам слева направо: что выдала первая нода, то получает вторая. В нашем примере данные — это имя и сумма из письма: триггер их достал, таблица записала, Telegram вставил в сообщение.

Что n8n умеет, а что нет

n8n хорошо подходит для задач вида «случилось А → сделай Б, В, Г». У него больше 400 готовых интеграций: Gmail, Telegram, Google Sheets, Notion, Slack, базы данных, нейросети. Если готового кубика нет, есть универсальная нода HTTP Request, которая обращается к любому сервису по адресу.

  • Подходит: уведомления, перенос данных между сервисами, отчёты по расписанию, обработка заявок, боты, цепочки с нейросетью.
  • Не подходит: сайты и приложения с интерфейсом, тяжёлые вычисления, обработка видео. n8n — про связи между сервисами, а не про замену программистов.

Все три инструмента решают одну задачу: соединяют сервисы без кода. Разница в деталях.

Главный плюс n8n: его можно поставить на свой сервер, и тогда данные не уходят на чужие площадки, а количество запусков ничем не ограничено.

Где n8n живёт

Есть два варианта. n8n Cloud — облако от создателей: зарегистрировались, и редактор открыт в браузере, ничего ставить не нужно. Self-hosted («у себя») — вы ставите n8n на свой сервер или компьютер, обычно через Docker. Интерфейс одинаковый, курс подходит для обоих.

!
Для этого курса ничего ставить не нужно

Каждый урок содержит тренажёры, которые повторяют интерфейс n8n. В них можно собирать workflow и нажимать кнопки прямо здесь. Когда закончите курс, откройте настоящий n8n: всё будет выглядеть знакомо. Там, где тренажёр что-то упрощает, стоит пунктирная плашка «В настоящем n8n здесь ещё…».

Что вы теперь умеете

  • Отличать workflow, ноду и триггер на любой картинке.
  • Решать, какую задачу стоит отдать n8n, а какую нет.
  • Выбирать, где n8n будет жить: облако или свой сервер.

Подумайте о своём: какая рутина у вас повторяется каждый день и устроена как «случилось → скопировал → отправил»? Запишите её одной фразой: «когда … → что сделать …». Это заготовка вашего первого workflow, она понадобится в уроке 10.

Как поставить n8n у себя за 2 минуты

Нужен Docker — программа, которая запускает другие программы в отдельной «коробке», чтобы ничего не настраивать вручную. Скачайте Docker Desktop с docker.com и установите как обычную программу. Затем одна команда в терминале:

docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

После запуска откройте в браузере http://localhost:5678. n8n попросит придумать почту и пароль администратора — это ваш вход в редактор. Часть -v n8n_data:/home/node/.n8n сохраняет ваши workflow между перезапусками, не убирайте её.

Итог урока

Главная мысль: n8n — конструктор автоматизаций. Вы собираете workflow из нод: первой стоит триггер («когда»), за ним шаги («что делать»). Данные бегут по стрелкам слева направо.

  • Workflow — вся цепочка, нода — один шаг, триггер — первая нода, которая запускает всё.
  • n8n берёт на себя рутину «случилось А → сделай Б, В».
  • Готовых интеграций сотни, а для остального есть HTTP Request.
  • n8n можно взять в облаке или поставить у себя, интерфейс одинаковый.
Проверка знаний
1. Какая задача подходит n8n лучше всего?
  • Собрать сайт магазина с корзиной, оплатой и доставкой
  • Записать заявку в таблицу и сообщить в Telegram
  • Обработать видео и выложить его на канал
  • Посчитать зарплату сотрудников в Excel
2. Менеджер просит: «сделай, чтобы заявки сами падали в таблицу и приходили в Telegram». Что вы создадите в n8n?
  • Один workflow: триггер и две ноды-шага
  • Две ноды без триггера, они запустятся сами
  • Два триггера: один для таблицы, другой для Telegram
  • Один триггер, он сам запишет и отправит
3. Какая нода отвечает на вопрос «когда запускать workflow»?
  • Последняя нода в цепочке
  • Триггер, он стоит первым
  • Нода Google Sheets
  • Любая нода с двумя стрелками
4. В какую сторону идут данные в workflow?
  • По стрелкам, от триггера к следующим нодам
  • От последней ноды обратно к триггеру
  • Во все ноды одновременно, сразу после запуска
  • В ту ноду, которую выбрал пользователь
5. Для нужного сервиса нет готовой ноды. Что сделать?
  • Взять ноду HTTP Request и адрес сервиса
  • Взять ноду Telegram, она универсальная
  • Добавить второй триггер для этого сервиса
  • Отказаться от n8n для этой задачи
