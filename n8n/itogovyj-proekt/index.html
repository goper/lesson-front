Итоговый проект: заявки с сайта

Собираем всё вместе: вебхук, условие, Telegram и таблица. Плюс чек-лист перед запуском.

Основная идея урока

Почти любая автоматизация укладывается в шаблон триггер → проверка → действие. В проекте вы соберёте его целиком: Webhook принимает заявку, If отделяет крупные, Telegram сообщает менеджеру, Google Sheets записывает остальные.

Задача

На сайте есть форма заявки: имя, почта, сумма. Нужно: заявки больше 1 000 сразу отправлять менеджеру в Telegram с именем и суммой, остальные тихо складывать в Google-таблицу. Работать должно само, круглосуточно.

План

  1. Триггер: Webhook Сайт отправляет форму методом POST на Production URL. Данные формы окажутся в body: $json.body.name, $json.body.amount.
  2. Проверка: If Одно условие из трёх частей. Что проверяем: {{ $json.body.amount }}. Оператор: Number → is greater than. С чем сравниваем: 1000. Крупные идут в true, остальные в false.
  3. Действие для крупных: Telegram К выходу true подключаем Telegram, текст: «Крупная заявка: {{ $json.body.name }}, {{ $json.body.amount }} руб.». Credential бота выбираем из списка, Chat ID менеджера вписываем в поле.
  4. Действие для остальных: Google Sheets К выходу false подключаем Google Sheets, операция Append Row. Выбираем credential, таблицу и лист, затем в каждый столбец (name, email, amount) пишем выражение из body.
  5. Запуск Проверяем через Test URL и Listen for test event, затем публикуем проверенную версию кнопкой Publish. Сайту отдаём Production URL.
Прогноз. После запуска у ноды If будет написано «3 items». Сколько элементов окажется на Telegram и на Google Sheets вместе?

Три. If раскладывает, но не теряет: сколько вошло, столько вышло суммарно по двум веткам. Если у Telegram «1 item», у Google Sheets будет «2 items». Проверьте это в тренажёре ниже и посмотрите, где именно видно эти числа.

Шаг 1. Собираем структуру

ТренажёрСоберите workflow: Webhook → If; к выходу true подключите Telegram, к выходу false — Google Sheets. Потом нажмите Execute workflow: прилетят три тестовые заявки.
!

Три заявки по кнопке — это упрощение для учёбы. Настоящий Webhook ничего не выдаёт сам: после Execute workflow n8n ждёт запрос на Test URL. Чтобы проверить цепочку, отправьте заявку с сайта или из формы, или закрепите один пойманный запрос булавкой Pin (урок 9).

Проверьте себя
В тренажёре суммы равны 1200, 350 и 900. If отправляет все три в true. Какое из условий даст такой результат?
  • Number: amount больше 0
  • Number: amount больше 1000
  • Number: amount равно 1200
  • Number: amount меньше 1000

Шаг 2. Настраиваем условие

ТренажёрДанные пришли от Webhook, поэтому лежат в body. Настройте условие «сумма больше 1000» и проверьте, что в true попала только одна заявка.

Шаг 3. Текст сообщения менеджеру

ТренажёрСоставьте текст сообщения для Telegram: «Крупная заявка: Анна, 1200 руб. Почта: anna@mail.ru».

Шаг 4. Записываем остальных в таблицу

Нода Google Sheets настраивается дольше остальных, поэтому пройдём её по порядку: доступ к аккаунту Google, выбор таблицы и листа, затем что положить в каждый столбец. В таблице «Заявки с сайта» уже есть три столбца: name, email, amount.

ТренажёрНастройте Google Sheets: создайте credential через «Sign in with Google», выберите таблицу «Заявки с сайта» и лист «Лист1», режим Map Each Column Manually, и впишите в каждый столбец выражение из body. Нажмите Execute step.

Шаг 5. Чек-лист перед публикацией

  1. Credentials выбраны в Telegram и Google Sheets, а не вписаны руками.
  2. Бот добавлен в чат менеджера, Chat ID проверен тестовым сообщением.
  3. Таблица открыта для того аккаунта Google, который выбран в credential.
  4. Прогнали тестовую заявку через Test URL: все ноды зелёные, в таблице появилась строка, в Telegram пришло сообщение.
  5. Сняли все булавки Pin, если ставили при отладке.
  6. В Settings → Error Workflow назначен сторож с Error Trigger.
  7. Проверен часовой пояс, если где-то используются даты.
  8. Опубликована проверенная версия с Webhook. Сайту отдан Production URL.
!
Вы собрали настоящий шаблон

Триггер → проверка → действие покрывает большинство задач: уведомления, перенос данных, сортировку заявок, отчёты. Меняется только содержимое кубиков, а не структура.

Что вы теперь умеете

  • Собирать шаблон триггер → проверка → действие под новую задачу.
  • Настраивать Google Sheets по порядку: credential → таблица → лист → столбцы.
  • Проверять workflow по чек-листу перед публикацией.

Теперь ваша рутина из урока 1. Триггер вы назвали в уроках 3 и 8, поля в уроке 4, условие в уроке 6, сервисы в уроке 7. Нарисуйте схему на бумаге: что запускает, что проверяет, что делает в каждой ветке. Это и есть ваш первый настоящий workflow; с этой схемой можно открывать n8n.

Куда дальше

  • Templates внутри n8n: откройте готовый workflow, похожий на вашу задачу, и разберите по нодам.
  • Документация docs.n8n.io: у каждой ноды есть страница с полями и примерами. Кнопка Docs есть прямо в окне ноды.
  • Нода Code: когда выражений мало, пишут несколько строк JavaScript или Python прямо в workflow.
  • AI Agent и ноды нейросетей: n8n умеет отправлять текст заявки модели, чтобы она, например, определила срочность.
  • Сообщество community.n8n.io: ответы на большинство вопросов уже есть.
Как бы выглядел этот workflow с нодой Code

Иногда проверку удобнее записать кодом. Нода Code в режиме «Run Once for Each Item» получает элемент как $input.item и возвращает новый. Например, добавить признак крупной заявки:

const body = $input.item.json.body;
return {
  json: {
    ...body,              // три точки: скопировать все поля из body как есть
    isBig: body.amount > 1000,
    label: body.amount > 1000 ? "VIP" : "обычная"
  }
};

После такой ноды If сравнивает уже готовое поле: {{ $json.isBig }} Boolean: is true. Но пока хватает выражений, Code не нужен: его сложнее читать и чинить.

Итог урока

Главная мысль: Шаблон «триггер → проверка → действие» собран целиком: Webhook, If, Telegram, Google Sheets. Данные вебхука лежат в body, условие в If, выражения в текстах, credentials в хранилище, публикация после проверки.

  • Сначала структура на холсте, потом настройка каждой ноды через Execute step.
  • Вебхук: body, Test URL для проверки, Production URL для сайта.
  • Google Sheets: credential → таблица → лист → столбцы.
  • Перед публикацией проверьте доступы, Chat ID, результаты теста и обработку ошибок.
Проверка знаний
1. Из каких трёх частей состоит типичный workflow?
  • Триггер, проверка, действие
  • Холст, панель нод, окно ноды
  • INPUT, параметры, OUTPUT
  • Save, Active, Executions
2. Данные пришли из ноды Webhook. Как обратиться к сумме из формы?
  • {{ $json.amount }}
  • {{ $json.body.amount }}
  • {{ $json.query.amount }}
  • {{ $json.form.amount }}
3. К какому выходу If подключить ноду для заявок, НЕ прошедших условие?
  • К выходу true
  • К выходу false
  • К обоим выходам
  • К выходу error
4. Что сделать, чтобы workflow с вебхуком принимал заявки с сайта постоянно?
  • Опубликовать workflow и дать сайту Production URL
  • Держать вкладку редактора открытой круглосуточно
  • Нажимать Listen for test event перед каждой заявкой
  • Поставить булавку Pin на ноду Webhook
5. В ноде Google Sheets выбран режим Map Automatically, а на выходе пустые строки. Почему?
  • Поля в body, а автоматика ищет их в корне
  • Таблица закрыта для записи, нужен другой credential
  • Режим Automatically работает только с Get Row(s)
  • Лист не выбран, строки ушли в первый попавшийся
6. Где в n8n хранится токен Telegram-бота?
  • В credentials, нода выбирает его по имени
  • В поле Chat ID ноды Telegram, рядом с текстом
  • В настройках workflow, пункт Settings
  • В Sticky Note рядом с нодой
7. Повторение. Workflow активен неделю, и вдруг Telegram перестал получать сообщения. С чего начать?
  • Открыть Executions и найти запуски с ошибкой
  • Удалить ноду Telegram и создать её заново с нуля
  • Снять workflow с публикации и опубликовать заново
  • Переписать условие в ноде If
8. Повторение. В тексте сообщения нужна сегодняшняя дата в виде 23.11.2026. Что написать?
  • {{ $now.toFormat('dd.MM.yyyy') }}
  • {{ $today.plus({days: 1}).toFormat('dd') }}
  • {{ $json.body.date.toFormat('dd.MM') }}
  • {{ date.now() }}
