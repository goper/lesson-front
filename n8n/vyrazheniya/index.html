Выражения: берём данные из предыдущих нод

Двойные фигурные скобки, $json и живой просмотр результата.

Основная идея урока

Выражение — способ сказать ноде «возьми значение из данных», а не писать его руками. Пишется в двойных фигурных скобках: {{ $json.email }}. Слово $json — это текущий элемент, пришедший на вход.

Зачем нужны выражения

В ноде Telegram есть поле Text — текст сообщения. Можно написать «Новая заявка от Анны». Но завтра заявку пришлёт Борис. Нужно, чтобы имя подставлялось из данных. Для этого вместо имени пишут выражение: Новая заявка от {{ $json.name }}. При выполнении n8n заменит скобки на значение поля name текущего элемента.

Fixed и Expression

У каждого поля в ноде есть два режима. Fixed — значение как есть, буква в букву. Expression — внутри могут быть скобки {{ }}, которые n8n вычислит. Переключатель появляется при наведении на поле. Самый быстрый способ: перетащить поле из панели INPUT в нужный параметр, и n8n сам включит Expression и напишет {{ $json.поле }}.

Прогноз. Поле Text оставили в режиме Fixed и написали «Привет, {{ $json.name }}». Что получит менеджер в Telegram?

Буквально «Привет, {{ $json.name }}», со скобками и знаком доллара. В режиме Fixed n8n ничего не вычисляет: что написано, то и уходит. Если вы ответили «Привет, Анна», заведите привычку: прежде чем писать скобки, посмотреть, что над полем подсвечено Expression.

!
Самая частая ошибка: забыли переключить в Expression

Если поле осталось в режиме Fixed, скобки никто не вычислит, и менеджер получит в Telegram буквально: Новая заявка от {{ $json.name }}. Увидели такое сообщение — проверьте, что над полем подсвечено Expression. В режиме Expression под полем появляется строка Result с готовым значением: «Новая заявка от Анна».

!
$json — это «текущий элемент на входе»

Если на вход пришло три элемента, нода выполнится три раза, и $json каждый раз будет другим элементом. Вложенные поля — через точку: {{ $json.customer.city }}. Элемент списка — через индекс: {{ $json.tags[0] }} (счёт с нуля).

ТренажёрТри задания подряд: составьте выражения для текста сообщения в Telegram. После каждого нажимайте Execute step.
ТренажёрСломайте. Выражение уже написано. Переключите поле в режим Fixed (переключатель над полем) и нажмите Execute step. Посмотрите в OUTPUT, что ушло бы менеджеру. Потом верните Expression и выполните ещё раз.
Проверьте себя
Что выведет {{ $json.customer.city }}, если customer — вложенная карточка с полем city «Минск»?
  • Текст customer.city без изменений
  • Минск
  • Всю карточку customer целиком
  • Ошибку: вложенные поля так не берут

Данные не из соседней ноды

$json видит только то, что пришло от предыдущей ноды. А если имя клиента было в триггере, а между ним и Telegram стоит ещё три ноды? Тогда обращаются к ноде по имени: {{ $('Webhook').item.json.name }}. Имя ноды берётся в кавычки точно так, как написано на холсте. Слово .item означает «тот же по счёту элемент, что обрабатывается сейчас»: для второй заявки возьмётся вторая.

Webhook → HTTP Request → Edit Fields → Telegram

В Telegram $json — это выход Edit Fields. Чтобы достать поле из Webhook, пишут $('Webhook').item.json.поле.

!
Если видите [undefined]

Серая надпись [undefined] в просмотре значит «такого поля нет». Чаще всего опечатка в имени поля или регистр: Email и email — разные поля. Сверьте с панелью INPUT. Красный [ERROR: …] — ошибка в самом выражении, например незакрытая кавычка.

Что вы теперь умеете

  • Подставлять поле текущего элемента через {{ $json.поле }}, вложенное через точку.
  • Собирать текст из нескольких выражений и считать внутри скобок.
  • Узнавать [undefined] и находить опечатку в имени поля по панели INPUT.

Подумайте о своём: какое сообщение вы хотели бы получать от своей автоматизации? Напишите его как шаблон, где на месте меняющихся частей стоят {{ $json.… }} с именами полей из урока 4.

Как выражения устроены внутри

Внутри {{ }} работает обычный JavaScript (язык, на котором написаны сайты). Поэтому там можно считать, вызывать методы строк и чисел, писать условия. n8n добавляет свои переменные: $json, $input, $('Нода'), $now, $env (настройки сервера n8n, которые задал администратор). Всё, что между скобками, вычисляется и подставляется как текст.

$input.first().json — первый элемент на входе, $input.all() — все элементы списком. Пригодится, когда нода выполняется один раз для всех (например, Code).

Даты в n8n — объекты библиотеки Luxon (готовый набор функций для дат): у них есть .plus({days: 1}), .minus({hours: 2}), .toFormat(...). Например, {{ $today.plus({days: 7}).toFormat('dd.MM') }} — дата через неделю.

Редактор выражений на весь экран

У поля в режиме Expression есть кнопка «Open expression editor». Открывается большое окно: слева переменные и данные нод, по которым можно кликать, в центре выражение, справа результат. Удобно для длинных выражений.

Итог урока

Главная мысль: Выражение в {{ }} подставляет значение из данных. $json — текущий элемент. Вложенность через точку, другая нода через $('Имя').item.json.

  • Переключатель Fixed / Expression, или перетащите поле из INPUT.
  • Строка Result показывает результат ещё до запуска.
  • [undefined] — поля нет, проверьте имя.
  • $now и $today — даты, внутри скобок можно считать и писать условия.
Проверка знаний
1. Как записать выражение, которое подставит поле email текущего элемента?
  • {{ $json.email }}
  • {{ $input.email }}
  • {{ json.email }}
  • $json.email
2. Нода Telegram стоит после Edit Fields. На вход пришли два элемента. Что подставит {{ $json.name }} во втором сообщении?
  • Имя из второго элемента
  • Имя из первого элемента, оно общее
  • Оба имени через запятую
  • Имя из ноды Webhook
3. В просмотре выражения серым написано [undefined]. Что это значит?
  • Такого поля в данных нет, вероятно опечатка
  • Выражение верное, значение появится при запуске
  • Поле есть, но нода ещё не подключена
  • Поле есть, но оно вложенное, нужен индекс
4. Как взять поле name из ноды «Webhook», если между ней и текущей нодой есть другие ноды?
  • {{ $json.Webhook.name }}
  • {{ $('Webhook').item.json.name }}
  • {{ $json.name }}, он видит все ноды
  • {{ $input.Webhook.name }}
5. Что выдаст {{ $json.amount * 2 }}, если amount равен 350?
  • Текст «350 * 2» без изменений
  • 700
  • Текст «3502»
  • Ошибку: внутри скобок считать нельзя
6. Менеджер получил сообщение «Заявка от [undefined] на 1200». Поле в режиме Expression. В чём дело?
  • В имени поля опечатка или не тот регистр
  • Поле осталось в режиме Fixed
  • Нода Telegram не поддерживает выражения в тексте
  • Число 1200 нужно было взять в кавычки
7. Повторение. В Edit Fields поле sum задано с типом String и значением 1200. Что покажет вкладка JSON на выходе?
  • "sum": "1200"
  • "sum": 1200
  • "sum": [1200]
  • Ошибку: число нельзя сделать строкой
8. Повторение. Ручной триггер запустил цепочку. Что лежит в $json у первой ноды после него?
  • Один пустой элемент без полей
  • Данные последнего письма из почты
  • Текущая дата и время запуска
  • Ничего: $json ещё не существует
